# Ekran Görüntüleri

1401 AOS'un tüm yeteneklerini gösteren tanıtım görselleri. Ekranlarda görünen
ürün adetleri, zayi kayıtları, sınav sonuçları ve şube verileri **tanıtım
amaçlı örnek verilerdir** — Firebase'e hiçbir zaman yazılmamıştır.

Şube isimleri 1401 Coffee'nin gerçek Coffee Shop şubelerinden alınmıştır.
